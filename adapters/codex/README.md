# Codex Adapter

Codex uses the repository root `AGENTS.md` as the primary entry point.

`adapters/codex/AGENTS.md` is a short adapter note for tools that copy adapter-specific files into another project. The canonical Codex instructions remain:

- `AGENTS.md`
- `shared/harness.yaml`
- `shared/institution-profile.yaml`
- `shared/references/permission-model.yaml`

The `.claude/` directory is not the Codex source of truth.
